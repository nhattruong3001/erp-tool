Hệ Thống Tiện Ích TGDD

📌 Hướng dẫn: Nhấp đúp mở file Setup.bat → Bấm Yes ở hộp thoại UAC để cấp quyền Administrator → chờ script chạy xong → khởi động lại máy để tên máy mới có hiệu lực.
⚠️ File ERP và package được tải tự động từ Google Drive. Hai file Google Drive phải được chia sẻ ở chế độ Anyone with the link → Viewer. Lưu ý: Windows không cho phép tên máy tính toàn chữ số — nếu bạn nhập ví dụ "179188", hệ thống sẽ tự thêm tiền tố thành "PC-179188".
📌 Hướng dẫn: Nhấp đúp mở file SetupCam.bat → Bấm Yes ở hộp thoại UAC → chờ giải nén và cài đặt xong → icon CamWin sẽ xuất hiện trên Desktop.
⚠️ Trước khi phát hành nội bộ, hãy sửa dòng SERVER_BASE thành đường dẫn máy chủ nội bộ chứa gói CAMWIN (.zip) và file cài đặt đi kèm.
