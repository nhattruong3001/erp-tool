Hệ Thống Tiện Ích TGDD

📌 Hướng dẫn: Nhấp đúp mở file Setup.bat → Bấm Yes ở hộp thoại UAC → chờ tải và cài đặt hoàn tất → khởi động lại máy.
⚠️ ERP_Setup.msi và package.zip được tải tự động từ Google Drive. Hai file Google Drive phải được chia sẻ: Anyone with the link → Viewer.

Nếu nhập tên máy chỉ gồm số, ví dụ 179188, hệ thống sẽ tự đổi thành PC-179188.

Windows giới hạn tên máy tối đa 15 ký tự.
📌 Hướng dẫn: Nhấp đúp mở file SetupCam.bat → Bấm Yes ở hộp thoại UAC → chờ giải nén và cài đặt → icon CamWin sẽ xuất hiện trên Desktop.
⚠️ Trước khi phát hành nội bộ, hãy sửa dòng SERVER_BASE thành đường dẫn máy chủ nội bộ chứa CamWin.zip.
